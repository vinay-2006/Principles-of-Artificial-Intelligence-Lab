# Principles of AI Lab – Experiment 1

This experiment demonstrates a basic AI-driven workflow for handling incoming emails or support tickets.

## Objective
To design a system that automatically analyzes, categorizes, and responds to common user queries, while routing complex cases to a human agent.

## Workflow Overview
1. Incoming email/ticket is received.
2. AI analyzes and categorizes the request.
3. If the query is common:
   - The system suggests or generates a response.
4. If the query is not common:
   - It is routed to a human agent.
5. Human agent resolves the issue and sends the response.
6. Process ends.
